# DataCo-Supply-Chain-Intelligence-Dashboard
Power BI supply chain analytics project for DataCo (2015–2018). Four interactive dashboards cover executive KPIs, shipping &amp; delivery, sales &amp; profitability, and a Weka model predicting late-delivery risk (AUC 0.771) on 172K order items. Key finding: 57.3% of deliveries are late, driven by shipping mode.
